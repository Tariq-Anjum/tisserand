# Code of conduct

We want this project to be a place where anyone can ask, disagree and contribute without being belittled.

**Expected:** be respectful and specific; criticise ideas and evidence, not people; assume good faith; accept that "I don't know" and "this was wrong" are useful answers.

**Not acceptable:** harassment, insults, discriminatory remarks, sexual content or attention, threats, publishing someone's private information, and sustained disruption of discussions.

**Scope:** issues, pull requests, discussions, and any space where someone represents the project.

**Enforcement:** report problems privately to the maintainer (see `SECURITY.md` for the private channel, or the contact in the repository profile). The maintainer may edit or remove contributions, warn, or ban, depending on severity, and will keep reporters' identities confidential.
