# Planning

| Asset | Type | Activation | Capabilities | Description |
|---|---|---|---|---|
| [bounded-plan](../skills/bounded-plan/SKILL.md) | skill | contextual | step-ordering, criteria-tracing, plan-sizing, plan-handoff, typed-ticket-map | Order an agreed goal into a sized plan of checked steps, or a typed ticket map when multi-session work has an unclear route. USE WHEN the goal is settled. NOT FOR unclear goals, architecture or building. |
| [decision-interview](../skills/decision-interview/SKILL.md) | skill | explicit | branch-interview, branch-ledger, pinned-terms, decision-records | Settle each open branch of a plan or decision, one question per turn with a recommended answer; record mode keeps only pinned terms and qualifying decisions. USE WHEN named. NOT FOR unnamed clarifying, design, plans or building. |
| [file-based-planning](../skills/file-based-planning/SKILL.md) | skill | contextual | progress-file, resume-state, dead-end-log | Keep a long task's progress, findings and dead ends in files so a reset or crash resumes from disk. USE WHEN work is long-running. NOT FOR ordering steps, handoff notes or doc drift. |
| [intent-contract](../skills/intent-contract/SKILL.md) | skill | contextual | intent-contract, done-criteria, assumption-ledger, ask-or-proceed-gate | Turn an unsettled request into a written contract with checkable done-criteria, then proceed or ask. USE WHEN goal, scope or done is unclear, or a plan needs critique. NOT FOR design, plans, known small edits, named interviews. |
